# Lab 1 — AI-Assisted Development Environment and Git Foundations

## Project
Neighborhood Listing Platform

This Lab 1 project demonstrates an AI-assisted Next.js development setup, basic Git workflow, and a simple accessible homepage.

## Team
- Ahmed Farah
- Partner: Diana Moron-Mendez (confirm GitHub username before inviting)

## Features
- Property Listings — explore available neighborhood homes.
- Local Sponsors — discover businesses in the neighborhood.
- Voice Help — a concept for easier voice-based searching.

These are introductory feature cards, not connected backend services.

## Run locally
1. Install Node.js 20 or later.
2. Clone this repository with `git clone https://github.com/AhmedFarah24/Lab-1-AI-Assisted-Development-Environment-and-Git-Foundations.git`.
3. In VS Code, open the cloned folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Visit http://localhost:3000.

## Production build
Run `npm run build`.

## Git practice
Create a branch with `git switch -c feature/lab1-update`, make a small edit, and commit your work. Push the branch and open a pull request on GitHub. Each teammate should commit from their own GitHub account so contributions can be verified.
